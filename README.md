# Sushi Restaurant Website

Welcome to the Sushi Restaurant Website project! This is a modern, fully responsive website built using **HTML**, **CSS**, and **JavaScript**. The site is designed to showcase a sushi restaurant and includes beautifully designed, adaptive menus that look perfect on any device.

## Features

- **Responsive Design**: Seamlessly adapts to desktops, tablets, and mobile devices.
- **Interactive Menus**: View sushi options with images, prices, and details.
- **Modern Aesthetic**: Clean, inviting design with attention to detail.
- **Smooth Navigation**: Easy-to-use navigation bar and smooth scrolling.
- **Custom Animations**: Engaging interactions using JavaScript.
- **Accessible**: Follows best practices for usability and accessibility.

## Pages

- **Home**: Welcome section with hero image and restaurant introduction.
- **Menu**: Extensive sushi menu, organized by type and responsive to screen size.
- **About Us**: Story and values of the restaurant.
- **Contact**: Contact form, map location, opening hours, and social links.

## Getting Started

1. **Clone the Repository**
    ```bash
    git clone https://github.com/yourusername/sushi-restaurant-website.git
    cd sushi-restaurant-website
    ```

2. **Open in Browser**
    - Simply open `index.html` in your preferred browser.
